# Boutique OM — click & collect (SAÉ 3.01)

Site click & collect de la boutique OM : catalogue, panier, compte client, commande à retirer en boutique, back-office `/admin`. Pas de paiement.
Base de code fournie par l'enseignant : garder son organisation et ses conventions.

## Règles générales
- Répondre en français, court, résultat d'abord, sans tableau.
- Mag écrit le code : expliquer simplement ce qu'il doit comprendre. Écrire le code seulement s'il dit « fais ».
- Ne modifier que ce qui est demandé. Ne lire que les fichiers utiles.
- Git : une branche par user story nommée comme l'US (ex. `DEC-B`), commits explicites en français, PR vers `main`. Jamais de push direct sur `main`.
- Noms de code en anglais, commentaires en français.
- HTML et CSS valides W3C, responsive mobile, tablette, desktop.
