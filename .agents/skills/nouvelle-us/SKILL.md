# Démarrer une US
1. Vérifier dans `README.md` que les US dont elle dépend sont fusionnées.
2. `git checkout main && git pull`, puis `git checkout -b <CODE-US>`.
3. Donner un plan court : fichiers à créer ou modifier, ce que Mag doit comprendre.
   **Attendre sa validation.**
